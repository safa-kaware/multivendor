# MultiVendor

A full-stack dynamic multi-vendor e-commerce platform built using PHP, MySQL, Bootstrap 5, and JavaScript.

## Features

- Customer authentication
- Multi-vendor marketplace
- Product management
- Product variations
- Shopping cart
- Wishlist
- Coupons and discounts
- Product reviews and ratings
- Order management
- Admin dashboard
- Vendor dashboard
- Sales reports
- REST API
- Payment gateway integration
- Responsive Bootstrap 5 design

## Technology Stack

- PHP
- MySQL
- Bootstrap 5
- JavaScript
- HTML5
- CSS3
- XAMPP
- InfinityFree
- Git & GitHub
